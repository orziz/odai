# 规则账本

本表登记 odai 治理里由真实失败、评测、用户要求或设计要求支撑的操作规则，说明每条写在哪里、为什么存在。改写、压缩或重组正文时，逐条核对本表规则仍在所列 owner 中完整成立，适用条件没有变窄，并更新“核对”列。

维护规则：

- 每条规则只有一个 owner。“细则”只列 owner 之外补充具体做法的位置，不得复述 owner 的规则本身。细则位置的措辞同样要逐条核对：0.7.0 曾把 dao 的方向性改进细则改写成“只把范围分歧交给用户对齐”，C31 随即从 4/4 降到 2/4。
- 登记的规则只有出现反证或用户明确决定时才能删除或降级；新增、改写或删除须在 CHANGELOG 写明问题和理由。
- 来源中的题号对应 [`plans/odai-canary.md`](../plans/odai-canary.md)，结果记录见 [`evaluation-results.md`](evaluation-results.md)。本表不重复题面或分数。
- 是否为某条规则的改动跑模型评测，按 `AGENTS.md` 的证据规则决定；全文核对本表是每次改动的最低要求。
