# 规则账本

本表登记 odai 治理里由真实失败、评测或设计要求支撑的操作规则，说明每条写在哪里、为什么存在。它替代已经退役的措辞校验：改写、压缩或重组正文时，逐条核对本表规则仍在所列 owner 中完整成立，适用条件没有变窄。

维护规则：

- 新增、改写、降级或删除本表规则，须在 CHANGELOG 写明要解决的问题和理由；“必须保持”的规则只有在出现反证或用户明确决定时才能删除。
- 来源中的题号对应 [`plans/odai-canary.md`](../plans/odai-canary.md)，结果记录见 [`evaluation-results.md`](evaluation-results.md)。本表不重复题面或分数。
- 是否为某条规则的改动跑模型评测，按 `AGENTS.md` 的证据规则决定；全文核对本表是每次改动的最低要求。
