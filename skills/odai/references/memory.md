# 状态与记忆

用户要求记住、以后照做、固化规则或流程，或需要写入跨任务信息、项目叠加层与项目技能时读取。本文件负责跨任务持久化的对象、位置与边界；任务内的跨轮状态由 `references/planning.md` 负责。

## 长期信息

- 只保存稳定、跨任务有用且可复核的事实或明确偏好，写入已有权威位置并保留来源、适用范围、最后确认时间和失效条件。
- 已有 owner 时原位更新：新规则取代已失效规则时替换原条目，不让新旧冲突并存，也不另建重复记忆。反馈推翻旧判断时更新同一事实与后续做法，不隐藏改判。
- 不从片段对话推断性格、情绪、身份或敏感信息。秘密、凭据、一次性观察、临时绕法和未采纳建议不固化；用户要求一并记下时，说明哪些不记及原因，只保存稳定部分。

## 项目叠加层

- `.odai/local.md` 只补项目事实、常量、禁区、术语和已有验收入口，不覆盖核心治理、宿主指令或当前用户决定。
- 它不充当任务状态、长期记忆或专业技能；不存在时不搜索替代文件，也不把对话偏好写进去。

## 规则与项目能力

- 跨任务规则缺口先完成当前任务，再将证据交给既有维护位置；没有维护授权不修改技能或项目规则，采纳后只保留一个规则来源。
- 用户明确要求固化项目流程，或实际重复使用已显示稳定收益时，可评估项目级技能：先检查已有能力，存在就原位更新；不存在时在项目声明的技能位置建立唯一能力，依据真实实例形成可发现、可重用、可验证的契约，写清规则来源、适用范围、输出契约和失效条件，不固化当期数据，只有预期的收益须标明。创建须有当前请求或项目约定授权，并同时完成本次结果。
- 稳定的专业工艺符合上述条件时可提炼为技能，不无限堆入项目叠加层。
