# 任务状态

只在任务确需跨轮恢复、且没有合适的现有状态载体时使用；普通改动不建账。只保留影响下一步的字段，不要求填满模板。面向用户展示时使用用户当前主要语言，正式产物另有约定时除外。

- 完整目标 / 用户原文来源：
- 当前有效要求 / 必须保持 / 不可接受结果：
- 用户修订及原文来源 / 明确取代了哪项要求：
- 当前范围 / 已有授权 / 仍需用户决定：
- 相关产物及基线：
- 已实现且已验证 / 对应要求、对象和证据：
- 已实现未验证 / 尚未实现：
- 失效证据 / 失效原因与影响范围：
- 未确认结果的动作 / 先查询何种回执：
- 下一项可验证动作 / 真正阻断它的条件：
- 唯一主状态或维护位置：

目标、修订与续作遵循 `references/planning.md`，完成判断遵循 `references/verification.md`，不在模板另设规则。
